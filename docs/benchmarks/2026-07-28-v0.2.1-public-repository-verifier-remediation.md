Five dependent public repository jobs then failed before inspecting their first public artifact.

## Root causes

The first failing command was:

```sh
gh release download "$GITHUB_REF_NAME" \
  --pattern ATTESTATION-linux-repositories.sigstore.json \
  --dir "$temporary"
```

Those jobs intentionally had no checkout. GitHub CLI therefore could not infer a repository and
exited with `fatal: not a git repository`. Running the same command outside a checkout with
`--repo Amekn/mealy` downloaded the retained bundle successfully.

While extracting and running the clean-install boundary directly, a second verifier weakness was
found: each `docker run ... bash -s` command redirected a checked program into Docker's standard
input but omitted `--interactive`. Docker did not attach that input, so the empty container process
could exit successfully without invoking APT, DNF, or Pacman.

Neither defect changes or implicates a release binary, package, repository file, signature,
attestation, tag, or release asset. The immutable v0.2.1 subjects remain unchanged.

## Remediation

- Every GitHub release operation now carries an explicit `OWNER/REPOSITORY`.
- One standalone verifier accepts and validates the repository, stable tag, exact source commit,
  HTTPS base URL, signing fingerprint, and empty evidence directory.
- A checkout-free regression runs that verifier outside Git metadata and fails unless both the
  release download and attestation verification carry the explicit repository.
- One shared package-manager installer uses `docker run --interactive`, and its regression requires
  non-empty APT, DNF, and Pacman programs plus an exact installed `mealyctl` version assertion.
- The tag workflow uses those shared entry points for future releases.
- A non-publishing `workflow_dispatch` workflow runs only from protected `main`, resolves the
  immutable annotated tag to a commit contained in `main`, verifies the original tag-workflow
  attestation and checked repository identity, runs five native clean-install lanes, and aggregates
  their result.
